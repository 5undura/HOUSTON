## 폴더 구조

```
Assets/
├─ _Project/            우리가 만든 것 전부
│  ├─ Scenes/           P1_Cockpit, P2_ControlRoom, Test/ (개인 테스트 씬)
│  ├─ Scripts/          Common / P1 / P2
│  ├─ Models/           Common / P1 / P2
│  ├─ Textures/         Common / P1 / P2
│  ├─ Materials/        Common / P1 / P2
│  ├─ Prefabs/          Common / P1 / P2
│  ├─ UI/               모니터 화면 그래픽, 폰트
│  ├─ Audio/            SFX / Voice
│  ├─ Shaders/
│  └─ Data/             퍼즐 정답 데이터 (P1·P2 공용)
└─ ThirdParty/          외부에서 받은 에셋만
ArtSource/              .blend, .psd 원본 (Assets 바깥)
```

- 양쪽에서 같이 쓰는 것(문, 해치 등)은 `Common`에
- 외부 에셋은 `ThirdParty`에만 넣고, 출처를 아래 **라이선스 기록**에 적기

## 작업 순서 (매번)

1. GitHub Desktop에서 **Fetch → Pull**
2. Unity에서 작업 후 저장
3. 내가 작업한 파일만 체크 → **Commit**
4. **Push**

---

## 꼭 지킬 규칙

- 작업 시작 전에 **항상 Pull**
- **작게, 자주** Commit
- **`.meta` 파일은 항상 같이 Commit**
- **메인 씬은 담당자만 수정**
  - `P1_Cockpit`
  - `P2_ControlRoom`
  - 나머지는 `Scenes/Test/Test_이름` 에서 테스트
- 모델러는 **모델 · 텍스처 · 머티리얼 · 프리팹**만 올리기 (씬 변경은 Commit하지 않고 Discard)
- 파일 **이름 변경 · 이동 · 삭제는 Unity 안에서만** (탐색기에서 하면 연결이 끊김)
- 모델 수정은 **같은 파일 이름으로 덮어쓰기** (지우고 다시 넣지 않기)
- `.blend`, `.psd` 원본은 **Assets 폴더 안에 넣지 않기**
- 충돌(Conflict)이 나면 억지로 해결하지 말고 **톡방에 먼저 말하기**

## Commit 메시지

```
[P1/P2/공통][모델/코드/UI/사운드] 작업 내용
```

예시
- `[P2][모델] 관제실 책상 추가`
- `[P1][코드] 4면 시점 전환`
- `[공통][UI] 경고창 그래픽 수정`

## 모델링 규칙 (IronLung 스타일 로우폴리)

**폴리곤 (삼각형 수)**

| 종류 | 기준 |
|---|---|
| 작은 소품 | 50 ~ 200 |
| 중형 오브젝트 | 200 ~ 600 |
| 큰 가구 | 500 ~ 1,500 |
| 벽 · 문 모듈 | 100 ~ 400 |
| 씬 전체 | 2 ~ 3만 이하 |

**텍스처**
- 크기: 32px (작은 소품) / 64px (기본) / 128px (최대)
- Unity 설정: Filter Mode `Point`, Generate Mip Maps `끔`, Compression `None`
- 노말맵 사용하지 않음

**내보내기**
- 1 Blender 단위 = 1m
- 피벗은 바닥 중앙 (회전하는 부품은 회전축에)
- Transform 적용 후 `.fbx` + `.png` 로 내보내기
- 누르거나 움직이는 부품(버튼, 레버, 전선 등)은 **따로 분리된 메시**로
- 모니터 화면 부분은 비워두기 (UI가 들어갈 자리)
- 파일명 규칙: `____` (팀에서 정한 뒤 작성)

**모델 올리는 순서**
1. `.fbx` → `Models/P1·P2`, `.png` → `Textures/P1·P2`
2. Unity에서 크기 · 방향 · 텍스처 설정 확인
3. 머티리얼 붙여서 `Prefabs/P1·P2` 에 프리팹으로 저장
4. `.fbx`, `.png`, 머티리얼, 프리팹 **+ 각각의 `.meta`** Commit

## 완료 기준

- **모델**: 프리팹으로 만들어져 테스트 씬에서 문제없이 보이면 완료
- **코드**: 다른 사람 컴퓨터(최신 Pull 상태)에서도 돌아가면 완료
